# HTTP APIs

The Nest app in `apps/api` is a JSON API. Pages are rendered by the SvelteKit app in `apps/web`. In development, Vite proxies `/api`, `/images`, and `/mcp` to the API.

- JSON app: request `.json`.
- Example: `GET /api/products/suggestions.json?q=bananas`.
- Example: `GET /api/lookup/:id` for the public product page.
- Product and receipt files are binary responses under `/images/`.
- MCP stays at `/mcp`.
