# HTTP APIs

The Nest app in `apps/api` returns JSON. The SvelteKit app in `apps/web` renders the UI. In development, Vite proxies `/api`, `/images`, and `/mcp` to the API.

- Example: `GET /api/products/suggestions.json?q=bananas`.
- Product and receipt files are binary responses under `/images/`.
- MCP stays at `/mcp`.
