# HTTP APIs

The Nest app in `apps/api` still renders the Handlebars UI. JSON routes stay beside it. Pages move to the SvelteKit app in `apps/web` one at a time. In development, Vite proxies `/api`, `/images`, and `/mcp` to the API.

- HTML app: request `.html` and replace a container with the response body. The server renders the markup; do not build DOM from JSON.
- JSON app: request `.json`.
- Example: `GET /api/products/suggestions.html?q=bananas`.
- Example: `GET /api/products/suggestions.json?q=bananas`.
- Product and receipt files are binary responses under `/images/`.
- MCP stays at `/mcp`.
